# BASE Design — BOQ & Quantity Takeoff

Website for **BASE Design**, quantity takeoff and BOQ services in Kuwait:
concrete, reinforcement (BBS) and blockwork quantities measured from
coordinated Revit models, for villas, towers, chalets and commercial work.

**Live:** https://jellox9991.github.io/base-design/

Static HTML/CSS/JS. No build step, no dependencies, no framework. Bilingual
English / Arabic with a full RTL layout. About 3 MB in total.

The old `/boq/` address redirects to the homepage, so links already shared
keep working.

---

## Editing the site

### `js/config.js`: contact details

```js
window.SITE = {
  whatsapp: "96597116574",          // digits only, no + and no spaces
  phoneDisplay: "+965 9711 6574",
  email: "you@example.com",
  formEndpoint: "https://formspree.io/f/xxxxxxxx"   // see "Contact form"
};
```

The WhatsApp button, phone number and email on the page all read from here.

### `boq/data.js`: the projects

One entry per project, with English and Arabic text. Names are district +
building type, never client names. Headline totals (m³ concrete, tonnes of
steel, storeys) are summed automatically from this file.

### `boq/models/NNN.js`: the 3D models

The Revit-derived structural geometry for each project, generated by
`tools/build_boq_models.py`. Don't edit by hand.

### Page text

Text lives in `index.html` as `data-en` / `data-ar` pairs on each element.
Messages generated by script (form notes, labels) are in the `L` table at the
top of `boq/boq.js`.

## Contact form

The form at the bottom of the page emails each enquiry through
[Formspree](https://formspree.io) (free plan: 50 submissions a month).

- Emails arrive with the subject `BOQ enquiry: <building type> · <name>`.
- A hidden spam-trap field (`_gotcha`) drops bot submissions.
- If sending fails, the visitor keeps what they typed and gets a one-tap
  "Send it on WhatsApp" link with the same message, so no lead is lost.
- Clearing `formEndpoint` switches the form to opening WhatsApp instead.

The endpoint is public by design (it is visible in the page source anyway),
so it is safe to commit. In Formspree's form settings you can restrict
submissions to your site's domain.

## Custom domain

1. Add a file named `CNAME` at the repo root containing your domain, e.g. `basedesign.com`
2. At your registrar, point the domain at GitHub Pages:
   - `A` records to `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - or a `CNAME` record for `www` to `jellox9991.github.io`
3. In the repo: **Settings → Pages → Custom domain**, then tick **Enforce HTTPS**

Also update the absolute URLs in `index.html`, `robots.txt` and `sitemap.xml`.
